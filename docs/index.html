Esan ERP

Enterprise Milling & Packaging Management System for Nile Harvest Foods Ltd.

Get started Live demo

About

esan is an ERP focused on milling and packaging operations. It helps manage production, inventory, and packaging workflows for food processing operations.

Features

  • Production planning & scheduling
  • Inventory & stock tracking
  • Packaging workflows and batch management
  • Reporting and exportable data
  • Role-based access and user management

Installation

esan is implemented using Python. A typical setup looks like this:

git clone https://github.com/Ideas-and-Concepts/esan.git
cd esan
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
# configure settings and run

Usage

Start the application (example):

export FLASK_ENV=development
flask run
